SYSTEM

OpsTracer design system

Two bands, one signal quartet, one amber action.

DS-01 documents the language the OpsTracer landing page ships today. The page runs a warm paper shell for editorial bands and the SRE Lead dark palette for the nav, the hero and every product panel. Colour speaks four times — amber, red, green, blue — and the only action colour is brand amber.

These values are the resolved output of opstracer-landing-page/index.html, read after all 22 override layers. The base token block at the top of that file is superseded — layer 6 replaces the surfaces, layer 8 flips nav and hero, layer 17 makes every primary action amber. Reading only the top of the file gives the wrong system.

BANDS

Paper for the argument. Dark for the product.

This is not a light/dark theme pair — both bands are on screen at once. The page opens dark (nav + hero), drops to warm paper for the editorial sections, and returns to dark wherever real product UI is shown. The dark band is a scoped token override on nav,.hero, not a theme flip.

VOICE

System / Voice

Technical, decisive, evidence-led.

The positioning is on-call plus AI root cause analysis, sold demo-led. Copy names the artifact — incident, evidence, deploy, rollback, RCA — and every claim is followed immediately by the product surface that proves it.

Show, then claim

Each argument band is followed by a real panel at real density. The proof is the screenshot, not an illustration.

Audit under pressure

Nothing is a black box: every conclusion links to the event behind it, and the UI shows the link.

One action

"Get a live demo" is the only call in the whole page. No self-serve sign-up, no secondary funnel.

TYPE

Foundations / Typography

Host Grotesk argues. DM Mono reports.

Two self-hosted families, split by meaning. Host Grotesk carries prose, navigation, actions, field labels, tabs and human-readable states. DM Mono is reserved for code and machine-readable facts such as timestamps, IDs, paths, tokens and measurements. Technical UI text is uppercase; literal source code keeps its syntax casing.

--font-sans

Host Grotesk

400 regular plus a medium file covering 500–900. Headlines run at 400; only card titles and values step to 500–600.

SHAPE

Foundations / Geometry

Square, with one corner cut.

Radius is zero. The signature is a notch on the bottom-right corner, cut with clip-path. It comes in two sizes because it is applied at two scales — 14px on actions and cards, 18px on product panels, 24px on the very wide integration card.

ICONS

Operational icons come from Nucleo Arcade and are stored locally as SVG source files. They render as one-colour masks that inherit currentColor, keeping status meaning in the surrounding label instead of introducing a second visual language.

RULES

Guidelines / Do & Don't

The decisions that keep this coherent.

Do

Repaint the notch outline. Clip-path removes the border along the diagonal — put it back with the gradient iso-line on every outlined element that is cut.

Don't

Leave a cut container with an open corner. A frame whose border stops short reads as a rendering bug, not a shape.

Do

Use amber for the single primary action, and for the one thing currently moving.

Don't

Introduce a second action colour. The blue in the signal quartet marks correlation and links — it is never a button.

Do

Give a scoped dark band its own color:var(--ink), or its headings inherit the paper ink and disappear.

Don't

Flip the whole theme to get a dark section. The bands coexist; only the band's tokens change.

Do

Use uppercase DM Mono for timestamps, IDs, paths, tokens, measurements and technical keys. Preserve original casing only in literal source code.

Don't

Set prose, navigation, actions, field labels, tabs or human-readable states in mono. Use Host Grotesk whenever the language needs sentence case.

Do

Pair every state colour with a word. The chip says "Resolved" as well as being green.

Don't

Rely on a dot alone. A colour with no label fails the moment the reader is colour-blind or the screen is dimmed.

Do

Show real density in proof panels — real service names, real timestamps, real error rates.

Don't

Draw placeholder rows. If the data is not real enough to show, the section is not ready.

Verified by counting the rendered markup: zero <table>, zero field wrappers, zero key/value or log blocks.

The landing page's stylesheet still carries CSS for several of these — form controls, key/value rows, an activity log, a control-plane panel — left over from an earlier revision. It is dead code. Nothing renders it, and it is not part of this system. Delete it rather than building on it.

If a future surface genuinely needs a sortable dataset, that is a new component and it needs its own specification.

BUILD

Guidelines / Implementation

Read the file bottom-up, not top-down.

The landing page's stylesheet is 22 numbered override layers deep. The base token block at the top is not the system — it is the starting point that later layers replace. Anyone picking up this codebase should resolve values in a browser rather than reading the first :root.

layer 5typeOne heading size — 55/65 — for every section below the hero.
layer 6surfacesOne warm paper for the light shell; three grounds consolidated to #ECEBE5.
layer 8dark bandNav and hero take the SRE Lead palette as a scoped override.
layer 15geometryThe notch keeps its outline — the iso-line repaint.
layer 16railRail marker matches the eyebrow; the numeral is dropped.
layer 17actionEvery primary action becomes brand amber with an ink label.
layer 18hierarchyThe quietest text tier lifts to #A49C95.
layer 22typeCanonical font assignment, authored last and marked important.
fonts

Four self-hosted woff2 under assets/fonts/ with font-display:swap. Two faces per family — regular at 400 and a medium covering the upper range — so nothing is synthetically bolded.

new section checklist

Rail marker · headline under 20ch · one primary action · every colour from a token · hairline top border · notch outline repainted · reduced-motion guard on anything that animates.

GAPS

Guidelines / Known gaps

What this system does not yet answer.

Recorded so the next person does not assume a decision exists where none does.

warm paper, cool inkdriftLayer 6 warmed the surfaces but left the ink ramp cool. Warm the ink or cool the paper — currently neither.
#F0A439 vs #F0A43AdriftThe button literal and the amber token differ by one digit. Pick one.
22 override layersdebtThe palette can only be known by resolving it in a browser. Flatten into one token block.
dead CSSdebtForm controls, key/value rows, activity log and a control-plane panel are styled but never rendered.
legacy radiidebtA few panels still carry 5–6px corners from before the square direction. Square them when touched.
two notch sizesopen14px and 18px both ship, plus 24px on one card. The rule is by scale, but it is not written down anywhere but here.
mixed colour spacesopenThe RCA panel uses oklch; everything else uses hex. Keep oklch scoped.
no spacing tokensopenEvery value is literal. Stay on the 2px grid and reuse nearby values.
embedded sectionsopenFour bands ship as captured markup with their own class names. Replace with native sections over time.
product surfacesopenSign-in, Control Plane and responder mobile predate this language. Rebuild from these primitives before treating them as reference.
